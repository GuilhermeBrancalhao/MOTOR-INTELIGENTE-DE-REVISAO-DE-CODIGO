# Checklist

- [ ] Todo item do backlog tem critério de priorização explícito registrado.
- [ ] Todo item fora de escopo tem motivo registrado, nunca apenas removido silenciosamente.
- [ ] Toda decisão que exige autoridade externa está sinalizada com a autoridade específica
  nomeada.
- [ ] O roadmap é revisado periodicamente contra o que de fato foi entregue.
- [ ] Nenhum item direcional de longo prazo carrega data comprometida.
- [ ] Dependência entre item de ciclos diferentes está declarada explicitamente, nunca inferida.


- [ ] A data da última revisão está visível diretamente no próprio documento de roadmap.
- [ ] Não existe versão informal paralela do roadmap divergindo da versão oficial registrada.

- [ ] Toda decisão de autoridade externa resolvida está registrada como histórico consultável para referência futura de casos semelhantes.

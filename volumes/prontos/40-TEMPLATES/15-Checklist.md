# Checklist

- [ ] Todo template do catálogo declara variável obrigatória e escopo explícitos.
- [ ] Nenhum template foi depreciado sem motivo e, quando possível, substituto declarado.
- [ ] Nenhum corpo de template contém termo de domínio específico proibido.
- [ ] Toda renderização de template valida variável obrigatória antes de produzir saída.
- [ ] Mudança de estrutura de template incrementa versão, nunca silenciosa.
- [ ] O catálogo é revisado periodicamente contra o uso real nos volumes e exemplos do acervo.


- [ ] Todo template significativo tem changelog próprio, separado do changelog geral do acervo.
- [ ] A lista de termos proibidos usada por este catálogo está sincronizada com a usada na
  auditoria de volume.

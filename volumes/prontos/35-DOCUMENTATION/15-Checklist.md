# Checklist

- [ ] Toda decisão arquitetural significativa tem ADR registrado com contexto, decisão e
  consequência.
- [ ] Nenhum ADR aceito foi editado diretamente; mudanças de decisão geram novo ADR.
- [ ] Toda documentação está versionada junto do código que descreve.
- [ ] Vigência de documentação crítica é verificada automaticamente, não apenas por revisão
  manual esporádica.
- [ ] Nenhum documento gerado automaticamente foi editado manualmente.
- [ ] Documentação para usuário e para mantenedor está em documentos estruturalmente distintos.


- [ ] Todo ADR inclui alternativas consideradas e descartadas, não apenas a decisão final tomada.
- [ ] Nenhum documento gerado tem fonte de verdade fora de controle de versão.

- [ ] O histórico de ADRs permanece consultável mesmo depois de decisões terem sido superadas por versões mais recentes.

# Checklist

- [ ] O indicador de qualidade é calculado por taxa de prova por mutação, não por cobertura de
  linha isolada.
- [ ] Todo release bloqueado pelo gate só prossegue com exceção explicitamente registrada.
- [ ] Toda dívida técnica está registrada como item completo, nunca apenas mencionada
  verbalmente.
- [ ] Qualidade é julgada por tendência de múltiplas medições, nunca por uma medição isolada.
- [ ] Toda regressão detectada é investigada antes de ser aceita como novo normal.
- [ ] O indicador agregado é sempre decomponível em submétricas nomeadas.


- [ ] Toda dívida técnica registrada tem data de revisão sugerida, não apenas data de criação.
- [ ] O gate e o histórico de tendência são tratados como mecanismos distintos, nunca confundidos
  como a mesma verificação.

# Escopo

Este volume cobre o catálogo de tipos de diagrama usados no acervo: propósito de cada tipo,
disciplina de prosa explicativa obrigatória, notação consistente, escolha por necessidade, e
escopo declarado por diagrama específico.

**Fronteira com `35-DOCUMENTATION`.** A disciplina geral de vigência de documentação — ADR,
versionamento, distinção gerado/manual — é daquele volume. Este volume aplica especificamente a
disciplina de vigência a diagrama como artefato, além de tratar de um problema que só existe para
diagrama: escolha do tipo certo de representação visual para a necessidade específica.

**Fronteira com `40-TEMPLATES`.** Catálogo de template textual reutilizável (prompt, documento,
configuração) é daquele volume. Este volume trata especificamente de diagrama — uma forma de
template visual, mas com disciplina própria o suficiente para merecer catálogo separado.

Não cobre ferramenta específica de renderização de diagrama (Mermaid é o que este acervo usa, mas
os princípios de catalogação, prosa obrigatória e escolha por necessidade valem independentemente
da ferramenta de renderização escolhida).


Essas duas fronteiras (35, 40) mantêm este volume especificamente sobre diagrama como artefato
visual — a disciplina geral de documentação (ADR, versionamento, vigência) já está no 35; este
volume aplica essa mesma disciplina ao caso específico de diagrama, que tem um problema adicional
que texto não tem: a escolha de qual tipo de representação visual usar para qual necessidade.

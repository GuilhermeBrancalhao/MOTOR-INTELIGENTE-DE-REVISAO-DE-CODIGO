# Conclusão

Código gerado por IA não é uma categoria especial que dispensa disciplina de engenharia — é
código, e precisa das mesmas garantias que qualquer código exige antes de afetar produção:
validado, revisado, rastreável até sua origem, e usado dentro do escopo para o qual foi pensado.
As seis regras deste volume tratam geração automática como uma técnica de produção de código, não
como um atalho que contorna o processo normal de qualidade.

A regra mais fácil de relaxar sob pressão de velocidade é Y4 — revisão humana obrigatória. É
tentador pular a revisão quando toda validação automatizada já passou, mas validação técnica
prova que o código funciona, não que ele faz a coisa certa — e essa segunda pergunta continua
exigindo julgamento humano, por mais sofisticado que o gerador automático se torne.

A tentação de tratar código gerado por IA como categoria especial cresce junto da capacidade dos
modelos — mas a pergunta que este volume responde não muda: como saber, com confiança real, que
este código específico faz o que deveria fazer, dentro do escopo que deveria cobrir. Nenhuma
sofisticação de gerador responde essa pergunta sozinha; validação, marcação, determinismo,
revisão humana e rastreabilidade continuam sendo o que de fato responde.

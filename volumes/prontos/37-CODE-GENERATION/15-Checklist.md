# Checklist

- [ ] Todo código gerado passa pela mesma validação (compilação, teste) que código escrito
  manualmente.
- [ ] Nenhum código gerado foi editado manualmente sem atualizar a especificação correspondente.
- [ ] A geração é reproduzível para a mesma especificação e o mesmo gerador.
- [ ] Todo código gerado tem revisão humana registrada antes de produção.
- [ ] A especificação que produz cada código gerado está versionada junto dele.
- [ ] Todo código gerado declara escopo explícito do que faz e do que não faz.


- [ ] Nenhuma versão mais capaz de modelo gerador dispensou a disciplina de validação e revisão
  exigida de versões anteriores.
- [ ] Especificações de geração bem-sucedidas estão disponíveis como referência para casos
  futuros semelhantes.

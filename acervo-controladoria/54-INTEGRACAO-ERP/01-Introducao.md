# INTEGRACAO-ERP

Duas superfícies diferentes de "trazer dado de fora para dentro": consumir
API de ERP (SAP, Oracle, Omie, IFS) quando ela existe, e normalizar arquivo
de exportação quando ela não existe. O caso real que preenche este volume
hoje é o segundo: 40+ bancos e fintechs de comissão não expõem API — o dado
chega como CSV de exportação, um formato nativo diferente por banco, sem
padrão nenhum entre eles.
